# Migas Amigas

Migas amigas es un proyecto de landing page en el que se muestran los productos de la panadería Migas Amigas


### Instrucciones de visualización

Usando el siguiente comando para clonar el repositorio:

```
git clone https://github.com/perdomomoralescarlos-ctrl/Ut1DOR

```

Es necesario para el correcto funcionamiento de la página web, que esta sea servida por un servidor web. Cualquier alternativa es válida, sin embargo, por simpleza, nosotros recomendamos usar el siguiente comando en la raíz del proyecto:

```
python -m http.server 8000 
```
En caso de disponer de python3, sería básicamente lo mismo:

```
python3 -m http.server 8000
```
